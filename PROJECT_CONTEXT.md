## Typography — one job per font
| Font | Job | Classes |
|---|---|---|
| Playfair Display | Headings | `.t-display .t-h1 .t-h2 .t-h3` (+ bare h1–h3) |
| Cormorant Garamond | Body / supporting prose (set at 1.25rem, weight 500; it runs small) | `.t-body .t-lead .t-subhead` |
| Courier Prime | Anything printed on an official document: serials, metadata, labels, buttons | `.t-doc .t-meta .t-label` |
| Special Elite | Typewritten annotations & notes | `.t-note` |
| Reenie Beanie | **Only** handwritten field entries and signatures (added beyond the brief because the licence card uses handwriting; do not use for anything else) | `.t-hand`, `.doc-field__value`, `.signature-block__ink` |

Sizes are fluid `clamp()` tokens (`--fs-*`); never hard-code font sizes.

## Components (all in style.css)
Surfaces: `.surface-parchment .surface-aged .surface-grain .surface-forest .surface-letter .surface-certificate .surface-distressed`
Buttons: `.btn` + `--primary --secondary --text --doc` (+ `--danger --sm --block`); disabled via `disabled`, `aria-disabled="true"` or `.is-disabled`.
Cards: `.card` (+ `--document --classified --polaroid --stacked`), `.card--passport` (+ `.frame-stars`, `.passport__layout`), ticket = `.ticket > .card--ticket` with `.ticket__stub`.
Borders: `.border-ink .border-double .border-dashed .border-gold .border-inset .frame-corners .frame-stars .divider(--double/--dashed/--dotted/--ornate) .perforation`
Badges: `.badge--approved --verified --classified --pending --archived --expired` (shape + colour, never colour alone).
Documents: `.doc-header .serial .doc-field .issue-date .signature-block .doc-footer .barcode .qr-slot .seal(--wax --sm --lg) .photo-frame .redact`
Stamps: `.stamp` + shape `--rect --round --oval` + colour `--red --green --teal --blue --black --gold` + rotation `--r1…--r4` or `--stamp-rot`; size via `--stamp-size`; parts `__top __main __sub __bottom __date __stars`; animated with `--press` then `.is-stamped`.
Icons: `<span class="icon icon--star" aria-hidden="true">` (coloured with `currentColor`).
Motion (animations.css): `.fade-in .reveal-up .js-reveal(+.is-visible) .stagger .unfold .unfold-wide .stamp--press .envelope(.is-open) .flip(.is-flipped) .lift .page-enter .page-exit .typewriter`
Layout: `.container(--narrow --content --max) .section .stack .cluster .grid(--2 --3 --4 --auto)`

## Breakpoints (single source of truth: responsive.css)
xs ≤359 · base 360–599 (default) · sm ≥600 · md ≥768 · lg ≥1024 · xl ≥1280. Touch targets ≥48px (52px on coarse pointers). Grids are 1 column on mobile.

## Rules for every future stage
1. **Mobile first.** Design at 390px, then enhance. Never hide essential content on mobile.
2. **Use tokens and existing classes.** Add new component styles to `style.css` (new numbered section), new motion to `animations.css`, new breakpoint tweaks to `responsive.css`. No inline hex colours, no new fonts, no new shadows.
3. **Square-ish paper.** Radius 0–4px. The only large radius is `--radius-license` (the rounded licence card).
4. **Stamps are the signature.** Reserve them for meaningful moments (approval, access, archive). Press them with `.stamp--press` + `.is-stamped`. Don't scatter them as decoration.
5. **Motion is tactile and short.** No bounce, float, looping backgrounds or parallax. Never add delays above ~0.5s. Every new animation must be covered by the reduced-motion block at the end of animations.css (the generic rule handles most).
6. **Never colour alone** to convey status. Pair with shape/text.
7. **Keep content on paper.** Text sits on a `.surface-*`; never directly on busy texture.
8. **No audio** (deferred past this stage).
9. **Humour lives in the copy**, not the styling: typewritten notes, deadpan official language, warm handwritten touches.
10. Use `Courier Prime` for UI chrome on documents (buttons, labels) and Cormorant for storytelling.

## Technical gotchas
- **Serve over HTTP, not `file://`.** CSS masks (stamps, icons) are blocked by Chrome's CORS rules on `file://`. Use a local server or GitHub Pages.
- Texture and icon URLs in `style.css` are relative to `css/` (`../assets/…`). Keep that folder layout.
- SVG stamps in `assets/stamps/` use a system monospace font (SVG-as-`<img>` can't load Google Fonts). Use the CSS `.stamp` where exact typography matters.
- `@view-transition` (cross-page fade) is progressive; unsupported browsers just navigate normally.
- The licence card's real photo, signature and QR code have not been added yet; the showcase uses placeholders. Real images go in `assets/images/` (Stage 03+); optimise to <200 KB, WebP/JPEG.

## Testing the showcase
Local: `cd` to project root, run `python3 -m http.server 8000`, open `http://localhost:8000/showcase.html`.
GitHub Pages: push to the repo, enable Pages (Settings → Pages → deploy from `main` / root), open `https://<user>.github.io/<repo>/showcase.html`. All paths are relative, so project-site sub-paths work.
Reduced motion: enable "Reduce motion" in your OS, reload; stamps appear instantly, typewriter text is complete, flips and envelope snap.
